一份代码，安卓 / iPhone / 网页 三端通用

数据经 AES-256 加密后同步到你名下的 GitHub 私有仓库，多端一方更新、另一方自动同步。
本演示按真实步骤逐一播放，可作为部署安装的跟练脚本。

键盘 ← → 翻页，空格 播放/暂停。
第一步

准备两个 GitHub 仓库

在 GitHub 新建两个仓库：一个放源码与自动打包配置，另一个只放加密数据文件（必须私有）。

📦 ledger-app

  • 存放应用源码 + CI 配置
  • 可见性：公开即可（代码无密钥）

🔒 ledger-data

  • 只存加密文件 data/ledger.enc
  • 可见性：必须 Private
  • 首次同步自动创建，无需手建
新建路径：GitHub 右上角 + → New repository → 填名 → 数据仓库选 Private → Create。
第二步

生成 Personal Access Token

App 通过 Token 读写私有仓库。只需生成一次，三端共用。

操作路径

  • 头像 → Settings → Developer settings
  • Personal access tokens → Tokens (classic)
  • Generate new token (classic)

关键设置

  • 权限勾选 repo（整项）
  • 过期：建议 1 年或无过期
  • 生成后复制保存（只显示一次）
安全：Token 在原生端存系统安全存储；网页端存浏览器本地。他人即便拿到 Token 也只能读到加密后的数据，无主密码无法解密。
第三步

把源码推到 ledger-app

在本地 ledger_sync_app 目录执行以下命令，把代码推上 GitHub（推送会触发后面的自动构建）。

cd ledger_sync_app
git init
git remote add origin https://github.com/<用户名>/ledger-app.git
git add .
git commit -m "init ledger app"
git branch -M main
git push -u origin main
推送到 main 分支后，GitHub Actions 会自动开始「构建安卓 APK」与「部署网页」两条流水线。
第四步 · 安卓

安卓安装：CI 自动打包 APK

无需本机装 Flutter，GitHub 云端自动编译并产出安装包。

① 等构建

  • 仓库 → Actions
  • Build Android APK 自动运行

② 下 APK

  • 该次运行 → Artifacts
  • 下载 app-release.apk

③ 安装

  • 传到手机，允许「未知来源」
  • 之后每次推代码自动重打包
想更省事：把 apk 上传到微信文件传输助手，手机端直接打开安装。
第五步 · iPhone 网页版

部署网页到 GitHub Pages

零本机环境，推送代码后 Actions 自动构建并上线网页（推荐 iPhone 走这条路径）。

开启 Pages

  • 仓库 Settings → Pages
  • Source 选 GitHub Actions

自动流水线

  • flutter create --platforms=web
  • 构建 → 注入 PWA 标签 → 部署

访问地址

  • https://<用户名>.github.io/ledger-app/
更私密：ledger-app 设为 Private 时，Pages 仅登录态可见；设公开则任何人可开网页，但数据仍在私有仓库且已加密，无泄露风险——推荐公开以便 iPhone 直连。
第六步 · iPhone

在 iPhone「添加到主屏幕」

用 Safari 打开网页，添加后即变为无浏览器边框的独立 App，体验接近原生。

① 打开

  • iPhone 用 Safari 访问网页地址

② 添加

  • 点底部「分享」→「添加到主屏幕」
  • 命名（如「记账」）→ 添加

③ 使用

  • 桌面出现图标，点开即独立运行
  • iOS 16.4+ 支持标准 PWA 安装
网页端数据与原生端完全互通：iPhone 记一笔，安卓打开会自动同步过来。
第七步 · 各端通用

App 内配置（首次使用）

每台设备只需设置一次主密码与 GitHub 连接信息。

① 主密码

  • 首次运行设置（至少 6 位）
  • 请牢记，忘记无法恢复数据

② GitHub 设置

  • 用户名：你的账号
  • 数据仓库名：ledger-data
  • Token：第二步复制的那个
  • 路径：data/ledger.enc

③ 启用

  • 点「测试连接」确认
  • 点「保存并同步」
  • 「+」添加收支，自动加密同步
另一端打开 App 会自动拉取并合并，无需重复配置。
原理速览

同步与加密怎么工作

每条记录带唯一 id 与更新时间；本地与仓库数据均为 AES-256 加密，主密码不一致绝不覆盖远端。

合并规则：同 id 以较新（updatedAt 大）者胜；不同 id 取并集。打开 App、回前台、每 60 秒自动对账。
完成

部署完成，多端互通 ✅

你现在拥有：一个私有加密数据仓库 + 一个自动打包/部署的 App 仓库。安卓装 APK，iPhone 用网页版，数据实时同步。

安卓 APK 已装 iPhone 已添加到主屏幕 数据私有加密 多端自动同步
排错：同步失败/401 → 重生成 Token 并勾选 repo；主密码遗忘 → 需清本地数据重设（原数据不可恢复）。详见 GUIDE.md 第八节。
